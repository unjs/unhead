Nuxt 3 and Nuxt 4 include and configure Unhead.

## No Separate Installation

Call `useHead()` or `useSeoMeta()` directly in your components. Default Nuxt SSR works without adding `parse5`.

If you enable `experimental.ssrStreaming`, run `npm install parse5@7` in your Nuxt app. See [HTML template imports](/docs/migration-guide/v3#html-template-imports) for other parser requirements.

For managed third-party scripts, install the official [`@nuxt/scripts` module](https://nuxt.com/modules/scripts).
