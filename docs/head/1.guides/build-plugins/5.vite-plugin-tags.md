title: Vite Plugin Tags
description: Convert Vite's HtmlTagDescriptor tags into an Unhead input, so SSR frameworks can push tags a Vite plugin declared.
navigation.title: Vite Plugin Tags
---

**Quick Answer:** `unhead/vite` exports `htmlTagsToHead()`, a pure helper
that turns Vite's `HtmlTagDescriptor[]` (the `transformIndexHtml` return
shape) into a `SerializableHead` you can push onto a server `Unhead` instance.

```ts
import { htmlTagsToHead } from 'unhead/vite'
import { createHead } from 'unhead/server'

const head = createHead()

// tags a Vite plugin returned from transformIndexHtml, or a future build manifest
head.push(htmlTagsToHead(tags))
```

`attrs` become tag props, string `children` become `innerHTML`, and `injectTo`
maps to `tagPosition`/`tagPriority`: `head-prepend` renders first in `<head>`,
`body-prepend` goes to the start of `<body>`, `body` goes to the end. Tags
with names outside `meta`, `link`, `script`, `style`, `noscript`, `base`, and
`title` are skipped without throwing.

This has no runtime dependency on `vite`; `HtmlTagDescriptor` is a local
structural type matching Vite's own.
