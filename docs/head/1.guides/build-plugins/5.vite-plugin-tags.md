---
title: Vite Plugin Tags
description: Convert Vite HtmlTagDescriptor output into an Unhead input for SSR.
navigation.title: Vite Plugin Tags
---

`unhead/vite` exports `htmlTagsToHead()`. Use it when your SSR integration has Vite descriptors to register with Unhead.

```ts
import type { HtmlTagDescriptor } from 'vite'
import { createHead } from 'unhead/server'
import { htmlTagsToHead } from 'unhead/vite'

export function applyViteTags(tags: HtmlTagDescriptor[]) {
  const head = createHead()
  head.push(htmlTagsToHead(tags))
  return head
}
```

Vite manifest support is still proposed in
[vitejs/ecosystem#15](https://github.com/vitejs/ecosystem/issues/15).

The helper supports `meta`, `link`, `script`, `style`, `noscript`, and `base`.
Other tags throw a `TypeError`. This includes `title`, which needs different character reference handling.
Keep unsupported descriptors in your framework's existing HTML transform.
String children are raw, because descriptors are trusted plugin output. Do not
pass user input as descriptor children.

`injectTo` maps to Unhead positions. Omitted `injectTo` and `head-prepend` map
to a high-priority head tag. `head`, `body-prepend`, and `body` map to their
matching Unhead positions. Unhead still applies normal dedupe and CAPO
ordering. A critical tag can render before a head-prepend tag. Exact descriptor
order and repeated effectful tags are not preserved.

`base` keeps its first effective Vite value. Vite groups omitted `injectTo` and
head-prepend before head. A head-prepend base keeps its high priority.
Base descriptors with body placement throw because Unhead cannot represent that placement.

The result uses Unhead's `attrs` input. Any framework can use this input directly:

```ts
head.push({
  script: [{
    attrs: { src: '/app.js?a=1&b=2', key: 'literal-html-attribute' },
    tagPosition: 'bodyClose',
  }],
})
```

`attrs` holds literal HTML attributes. Names such as `key`, `tagPosition`, and
`innerHTML` stay HTML attributes. They do not become Unhead controls.
String attributes stay raw for Unhead dedupe and client DOM updates. Unhead
escapes ampersands and double quotes during SSR serialization.
The input stays JSON-serializable for streaming and client replay.
Hooks receive normalized values through `tag.props`.

Nested `attrs` values override matching flat attributes on the same tag.
A `true` value renders a bare attribute. `false`, `null`, and `undefined` omit it.
Marker meta tags can omit `content`.

Literal class and style strings replace the previous value when tags merge.
Their whitespace and CSS declarations stay intact.
Structured class and style inputs retain their existing merge behavior.

Flat inputs retain existing character reference handling.
For example, flat `content: '&copy;'` renders a copyright symbol during SSR.
Nested `attrs: { content: '&copy;' }` renders the literal text `&copy;`.
Template parsing retains its existing behavior.

`vite` is an optional peer of `unhead`. `HtmlTagDescriptor` is re-exported as a
type, with no runtime Vite dependency.
