---
title: compileTags()
description: API reference for compileTags() and dynamicValue(), which turn static head input into compiled tags.
---

```ts
import { compileTags } from 'unhead/compiled/compile'

const result = compileTags({
  title: 'Home',
  meta: [{ name: 'description', content: 'Welcome' }],
})
if (result._tag === 'Ok')
  head.push(result.tags)
```

`compileTags()`{lang="ts"} turns static head input into compiled tags. It applies the same normalize, dedupe, and weight rules as a normal call. It keeps no state and never throws. If it cannot prove the input, it returns `Bail` with a reason.

The bundler [`compile` option](/docs/vue/head/guides/core-concepts/compiler-mode) calls it for you. Call it yourself for head input that a component does not own, such as a static app head.

::note
`compileTags()`, `dynamicValue()`, and the compiled tag format are experimental. They may change in a minor release.
::

## API Reference

```ts
function compileTags(input: unknown, options?: CompileOptions): CompileResult

type CompileResult
  = | { _tag: 'Ok', tags: CompiledTags, valueCount: number }
    | { _tag: 'Bail', reason: string }

interface CompileOptions {
  /** The number of dynamic values in the input. */
  dynamicValues?: number
}
```

Push compiled tags with `head.push(compiledTags)` on a compiled server head, a strict head, or a lazy head. Treat `CompiledTags` as opaque data. Store it at module scope, so every request shares one set of compiled tags.

## Dynamic values

`dynamicValue(index)` returns a token that marks dynamic value `index` in a string value. Set `dynamicValues` to the number of dynamic values. Pass their values as `values` when you push the compiled tags:

```ts
import { compileTags, dynamicValue } from 'unhead/compiled/compile'

const result = compileTags({
  script: [{ id: 'app-data', type: 'application/json', innerHTML: dynamicValue(0) }],
}, { dynamicValues: 1 })

if (result._tag === 'Ok')
  head.push(result.tags, { values: [JSON.stringify(data)] })
```

A dynamic value cannot decide the identity, weight, or merging of a tag. For example, a dynamic value in `meta.name` or in `class` returns `Bail`. The [Dynamic values](/docs/vue/head/guides/core-concepts/compiler-mode#dynamic-values) section lists these places.
