---
title: compileTags()
description: API reference for compileTags() and dynamicValue() from unhead/compiled/server. They turn head input into compiled tags for the compiled server head.
---

```ts
import { compileTags } from 'unhead/compiled/server'

const result = compileTags({
  title: 'Home',
  meta: [{ name: 'description', content: 'Welcome' }],
})
if (result._tag === 'Ok')
  head.push(result.tags)
```

`compileTags()`{lang="ts"} turns static head input into compiled tags. It applies the same normalize, dedupe, and weight rules as a normal call. It keeps no state and never throws. If it cannot prove the input, it returns `Bail` with a reason.

The bundler [`compile` option](/docs/vue/head/guides/core-concepts/compiler-mode#server-half) calls it for you. Call it yourself for server head input that a component does not own, such as a static app head.

::note
`compileTags()`, `dynamicValue()`, and the compiled tag format are experimental. They may change in a minor release.
::

## API Reference

```ts
function compileTags(input: unknown, options?: CompileOptions): CompileResult

type CompileResult
  = | { _tag: 'Ok', tags: CompiledTags, valueCount: number }
    | { _tag: 'Bail', reason: string }

interface CompileOptions {
  /** The number of dynamic values in the input. */
  dynamicValues?: number
  /** The `tagPriority` entry option, held in each tag. */
  tagPriority?: number | 'critical' | 'high' | 'low'
}
```

Push compiled tags with `head.push(compiledTags)` on a [compiled server head](/docs/head/api/compiler-mode/compiled-server-head). Other heads take normal input only. Treat `CompiledTags` as opaque data. Store it at module scope, so every request shares one set of compiled tags.

## Entry priority

An entry option takes the entry off the server memo. To give every tag of an entry one priority, pass `tagPriority` to `compileTags()` and push the compiled tags with no options:

```ts
import { compileTags } from 'unhead/compiled/server'

// the same tags as head.push(input, { tagPriority: 'low' })
const result = compileTags({ templateParams: { site: { name: 'My Site' } } }, { tagPriority: 'low' })
if (result._tag === 'Ok')
  head.push(result.tags)
```

Template params cannot hold a priority in their input, so this is the only way to keep a low priority `templateParams` entry compiled. A `before:` or `after:` priority returns `Bail`.

## Dynamic values

`dynamicValue(index)` returns a token that marks dynamic value `index` in a string value. Set `dynamicValues` to the number of dynamic values. Pass their values as `values` when you push the compiled tags:

```ts
import { compileTags, dynamicValue } from 'unhead/compiled/server'

const result = compileTags({
  script: [{ id: 'app-data', type: 'application/json', innerHTML: dynamicValue(0) }],
}, { dynamicValues: 1 })

if (result._tag === 'Ok')
  head.push(result.tags, { values: [JSON.stringify(data)] })
```

A dynamic value cannot decide the identity, weight, or merging of a tag. For example, a dynamic value in `meta.name` or in `class` returns `Bail`. The [Dynamic values](/docs/vue/head/guides/core-concepts/compiler-mode#dynamic-values) section lists these places.

To read the input of a compiled entry, read `entry.input`. It reads as the head input the compiled tags came from.
