---
title: compileTags()
description: API reference for unhead/compiled, the entry for module authors and tooling. compileTags(), dynamicValue(), toHeadInput(), and readCompiledEntry() turn head input into compiled tags and back.
---

```ts
import { compileTags } from 'unhead/compiled'

const result = compileTags({
  title: 'Home',
  meta: [{ name: 'description', content: 'Welcome' }],
})
if (result._tag === 'Ok')
  head.push(result.tags)
```

`compileTags()`{lang="ts"} turns static head input into compiled tags. It applies the same normalize, dedupe, and weight rules as a normal call. It keeps no state and never throws. If it cannot prove the input, it returns `Bail` with a reason.

The bundler [`compile` option](/docs/vue/head/guides/core-concepts/compiler-mode) calls it for you. Call it yourself for head input that a component does not own, such as a static app head.

::note
`compileTags()`, `dynamicValue()`, `toHeadInput()`, `readCompiledEntry()`, and the compiled tag format are experimental. They may change in a minor release.
::

All four functions come from `unhead/compiled`, for module authors and tooling. A bundler keeps only the functions you import, so `readCompiledEntry()` alone adds no compiler code.

## API Reference

```ts
function compileTags(input: unknown, options?: CompileOptions): CompileResult

type CompileResult
  = | { _tag: 'Ok', tags: CompiledTags, valueCount: number }
    | { _tag: 'Bail', reason: string }

interface CompileOptions {
  /** The number of dynamic values in the input. */
  dynamicValues?: number
}
```

Push compiled tags with `head.push(compiledTags)` on a compiled server head or a lazy head. Treat `CompiledTags` as opaque data. Store it at module scope, so every request shares one set of compiled tags.

## Dynamic values

`dynamicValue(index)` returns a token that marks dynamic value `index` in a string value. Set `dynamicValues` to the number of dynamic values. Pass their values as `values` when you push the compiled tags:

```ts
import { compileTags, dynamicValue } from 'unhead/compiled'

const result = compileTags({
  script: [{ id: 'app-data', type: 'application/json', innerHTML: dynamicValue(0) }],
}, { dynamicValues: 1 })

if (result._tag === 'Ok')
  head.push(result.tags, { values: [JSON.stringify(data)] })
```

A dynamic value cannot decide the identity, weight, or merging of a tag. For example, a dynamic value in `meta.name` or in `class` returns `Bail`. The [Dynamic values](/docs/vue/head/guides/core-concepts/compiler-mode#dynamic-values) section lists these places.

## toHeadInput()

```ts
function toHeadInput(compiledTags: CompiledTags, values?: readonly unknown[]): Record<string, any>
```

Rebuilds head input from compiled tags. Each dynamic value becomes the value at its index in `values`. Use it with `readCompiledEntry()` to inspect the tags of a head entry:

```ts
import { readCompiledEntry, toHeadInput } from 'unhead/compiled'

for (const entry of head.entries.values()) {
  const content = readCompiledEntry(entry)
  if (content)
    console.log(toHeadInput(content.tags, content.values ?? []))
}
```

The result is a new object, so you can change it. A change to it does not change the head.

## readCompiledEntry()

```ts
function readCompiledEntry(entry: HeadEntry<any>): CompiledEntryContent | undefined

interface CompiledEntryContent {
  tags: CompiledTags
  values: readonly unknown[] | undefined
  /** True for an entry from a `useSeoMeta()` call. */
  seoMeta?: true
}
```

Returns the compiled tags of an entry in `head.entries`, and their values. It reads entries of the compiled server head and of the lazy head. It returns `undefined` for an entry with normal input. It does not render and does not copy the tags.

- On the compiled server head, a `values` function runs at the first render. Before that, `values` is `undefined`.
- On the lazy head, a patch that waits for the runtime comes first. After the full runtime loads, every entry holds normal input, so it returns `undefined`.

`seoMeta` is `true` when the entry came from a compiled `useSeoMeta()` call. Such an entry holds no `_flatMeta`. To read its title and description, pass the result to `toHeadInput()`:

```ts
import { readCompiledEntry, toHeadInput } from 'unhead/compiled'

for (const entry of head.entries.values()) {
  const content = readCompiledEntry(entry)
  if (content?.seoMeta && content.values) {
    const input = toHeadInput(content.tags, content.values)
    const description = input.meta?.find((meta: { name?: string }) => meta.name === 'description')?.content
    console.log(input.title, description)
  }
}
```
