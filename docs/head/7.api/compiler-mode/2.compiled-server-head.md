---
title: Compiled Server Head
description: API reference for the compiled server head and the strict head, plus prepareHeadInput(), readCompiledEntry(), and renderSSRHead() for compiled tags.
---

```ts
import { createHead } from '@unhead/vue/compiled/server'

const head = createHead()
app.use(head)
```

The compiled server head renders compiled tags and normal input. It produces the same HTML as the server head from `@unhead/vue/server`. A head with no render hook listeners takes a faster path for its compiled tags. Read the [Compiler Mode guide](/docs/vue/head/guides/core-concepts/compiler-mode) for setup.

::note
The compiled server head, the strict head, and their exports are experimental. Their API may change in a minor release.
::

## Entry points

| Entry point | Exports |
| --- | --- |
| `@unhead/vue/compiled/server` | `createHead`, `prepareHeadInput`, `renderSSRHead`, `transformHtmlTemplate`, `prepareTemplate`, `propsToString`, `VueHeadMixin` |
| `unhead/compiled/server` | `createHead`, `prepareHeadInput`, `readCompiledEntry`, `renderSSRHead`, `createServerRenderer`, and the `unhead/server` utilities |
| `@unhead/vue/compiled/server-strict` | `createHead`, `renderSSRHead`, `templateParams` |
| `unhead/compiled/server-strict` | `createHead`, `renderSSRHead`, `createServerRenderer`, `templateParams` |

## createHead()

```ts
// @unhead/vue/compiled/server
function createHead(options?: Omit<CompiledServerHeadOptions, 'propResolvers'>): CompiledVueHeadClient

// unhead/compiled/server
function createHead<T>(options?: CompiledServerHeadOptions): CompiledServerUnhead<T>
```

The options are the options of the server `createHead()`. The `init` option also takes compiled tags. The Vue export sets `propResolvers` itself.

`head.push(input, options)` takes normal input or compiled tags. Pass dynamic values as `options.values`. The `values` option can be an array, or a function that runs once, before the first render reads it.

These make the head use the full runtime for every render. The output stays the same:

- A listener on a render hook: `entries:resolve`, `entries:normalize`, any `tags:` hook, `ssr:beforeRender`, `ssr:render`, or `ssr:rendered`.
- A custom `tagWeight` option.
- A custom prop resolver on the `unhead/compiled/server` head.

`TemplateParamsPlugin` runs on the faster path.

## prepareHeadInput()

```ts
function prepareHeadInput<T extends object>(input: T): T | CompiledTags
```

Compiles head input once, and returns compiled tags when it can. If the input cannot compile, it returns the input. Push the result with `head.push()`.

The input object is the cache key. Call it at module scope, and do not change the input afterwards:

```ts
import type { UseHeadInput } from '@unhead/vue'
import { prepareHeadInput } from '@unhead/vue/compiled/server'

const icons = prepareHeadInput({
  link: [{ rel: 'icon', href: '/favicon.ico' }],
} satisfies UseHeadInput)

// in each request
head.push(icons)
```

Add `satisfies UseHeadInput` to an object literal. Without it, TypeScript widens values such as `rel` to `string`, and `head.push()` rejects the result.

If you build input in each request, keep the `compileTags()` results on your renderer instead. See [Push compiled tags for renderer input](/docs/nuxt/head/guides/framework-integration/compiler-mode#push-compiled-tags-for-renderer-input).

## readCompiledEntry()

```ts
function readCompiledEntry(entry: HeadEntry<any>): CompiledEntryContent | undefined

interface CompiledEntryContent {
  tags: CompiledTags
  values: readonly unknown[] | undefined
}
```

Returns the compiled tags of an entry in `head.entries`, and their values. It returns `undefined` for an entry with normal input. It does not render and does not copy the tags.

A `values` function runs at the first render. Before that, `values` is `undefined`. Pass the result to [`toHeadInput()`](/docs/head/api/compiler-mode/compile-tags#toheadinput) to read the tags as head input.

## renderSSRHead()

```ts
function renderSSRHead(head: Unhead<any>, options?: RenderSSRHeadOptions): SSRHeadPayload
```

Renders a head to its HTML parts. `transformHtmlTemplate()` from the same entry calls it for you. `unhead/compiled/server` also exports `createServerRenderer(options)`, which returns a render function with fixed options.

## Strict head

```ts
import { createHead, templateParams } from '@unhead/vue/compiled/server-strict'

const head = createHead({ plugins: [templateParams] })
```

The strict head renders compiled tags only. It has no normal input path, no hooks, and no full runtime. It throws on anything else:

- Normal input, for example a head call that did not compile.
- The `hooks`, `tagWeight`, or `propResolvers` options, or a read of `head.hooks`.
- A plugin other than `templateParams`.
- An entry option other than `values`, `head`, and `onRendered`.
- A value that is not a string or a finite number.

`templateParams` applies the template params rules without hooks. Pass it in `plugins` when the app uses template params.

`renderSSRHead(head, { omitLineBreaks })` from the strict entry renders a strict head. `transformHtmlTemplate()` pushes the head tags of the HTML template as normal input, so it throws on a strict head. Use `transformHtmlTemplateRaw()` from `unhead/compiled/server`, which leaves the template's own head tags in place.
