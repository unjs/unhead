---
title: createLazyHead()
description: API reference for createLazyHead(), acceptCompiledTags(), readCompiledEntry(), and lazyTemplateParams, the client head that loads its DOM runtime lazily.
---

```ts
import { createLazyHead } from '@unhead/vue/lazy'

const head = createLazyHead()
app.use(head)
```

`createLazyHead()`{lang="ts"} creates a client head for a server rendered page. It stores entries without touching the document. It loads the DOM runtime at idle, or when a change must reach the document. Read the [Lazy Head guide](/docs/vue/head/guides/core-concepts/lazy-head) for setup and load triggers.

::note
`createLazyHead()`, `acceptCompiledTags()`, `readCompiledEntry()`, and `lazyTemplateParams` are experimental. Their API may change in a minor release.
::

## Entry points

| Entry point | Exports |
| --- | --- |
| `@unhead/vue/lazy` | `createLazyHead`, `acceptCompiledTags`, `lazyTemplateParams` |
| `unhead/lazy` | `createLazyHead`, `acceptCompiledTags`, `readCompiledEntry`, `lazyTemplateParams` |

The Vue export adds the Vue plugin install and detects calls the server never ran. Use `unhead/lazy` only to build an adapter for another framework.

## API Reference

```ts
function createLazyHead(options?: CreateLazyHeadOptions): VueLazyHead
```

### Options

`CreateLazyHeadOptions` takes every option of the client `createHead()`, plus these:

| Option | Type | Description |
| --- | --- | --- |
| `lazyPlugins` | `() => Promise<HeadPluginInput[]>` | Plugins that load with the runtime. Their code stays out of the eager chunk. |
| `onLoadError` | `(error: unknown) => void` | Receives the error when the runtime chunk fails to load. The default logs with `console.error`. |
| `isClientOnlyPush` | `() => boolean` | Returns `true` when the current push cannot be in the server rendered head. During hydration, such a push loads the runtime at once. The Vue export sets it. |

A custom `render` option makes the head use the full runtime.

### Returns

The head has the methods of the client head, plus these:

| Method | Description |
| --- | --- |
| `push(input, options?)` | Adds normal input or compiled tags. Pass dynamic values as `options.values`. Returns an entry with `patch()` and `dispose()`. |
| `load()` | Loads the runtime now. Safe to call more than once. Resolves `true` on success and `false` on failure. |
| `blockLoad()` | Blocks the load during a navigation, and cancels a pending idle load. The next `render()` releases it. A direct `load()` still runs. |
| `render()` | Before the runtime loads, it marks the end of hydration and releases a load block. If entries changed, it loads at once, unless a `dom:beforeRender` pause blocks it. Otherwise it arms the idle load. After the runtime loads, it renders. |

`push()` and `patch()` take `LazyEntryOptions`. It adds `values?: readonly unknown[]`, the values for the dynamic values of compiled tags.

## acceptCompiledTags()

```ts
function acceptCompiledTags<T>(head: LazyUnhead<T>): LazyUnhead<T>
```

Lets the head load the compiled runtime when every entry holds compiled tags. Otherwise the head loads the full runtime, which also renders compiled tags. Call it where you create the head:

```ts
import { acceptCompiledTags, createLazyHead } from '@unhead/vue/lazy'

const head = createLazyHead()
acceptCompiledTags(head)
```

The first compiled head call also calls it. An idle load that starts before that call loads the full runtime. A bundle that never calls `acceptCompiledTags()` keeps no compiled runtime code.

## readCompiledEntry()

```ts
import { readCompiledEntry } from 'unhead/lazy'

function readCompiledEntry(entry: HeadEntry<any>): CompiledEntryContent | undefined
```

Returns the compiled tags of an entry in `head.entries`, and the `values` of its options. If a patch waits for the runtime, it returns the compiled tags of the patch. It returns `undefined` for an entry with normal input. After the full runtime loads, every entry holds normal input.

Pass the result to [`toHeadInput()`](/docs/head/api/compiler-mode/compile-tags#toheadinput) to read the tags as head input. `toHeadInput()` lives in `unhead/compiled/compile`, so the eager chunk keeps no code for it.

## lazyTemplateParams

A plugin that stands in for `TemplateParamsPlugin` on the lazy head. It loads `TemplateParamsPlugin` when the runtime needs it. The compiled runtime needs it only when a tag value holds `%`.

```ts
import { createLazyHead, lazyTemplateParams } from '@unhead/vue/lazy'

const head = createLazyHead({ plugins: [lazyTemplateParams] })
```
